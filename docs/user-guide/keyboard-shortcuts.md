# Keyboard shortcuts

OpenTerm5 follows MetaTrader 5's shortcuts where they exist. On macOS, use **Cmd** where this page says
**Ctrl**. Shortcuts are ignored while you type in a text field.

## General

| Shortcut | Action |
|---|---|
| F9 | New order |
| F11 | Full screen |
| Ctrl+1 to Ctrl+5 | Switch workspace: Trading, Trade Copier, Signals, Automation, Journaling |
| Ctrl+O | Options (connection) |
| Ctrl+Shift+A | Switch between trading and analysis mode |
| Ctrl+= and Ctrl+− | Zoom the whole interface in and out, from 50% to 200%. Works in dialogs and text fields too |
| Ctrl+0 | Interface back to 100% |
| Escape | Close the open dialog or menu, cancel the risk planner, or return to the cursor tool |

## Panels

| Shortcut | Action |
|---|---|
| Ctrl+M | Show or hide Market Watch |
| Ctrl+N | Show or hide the Navigator |
| Ctrl+T | Show or hide the Toolbox |
| Ctrl+D | Show or hide the Data Window |
| Alt+B | Show or hide Depth of Market |
| Ctrl+U | Symbols |

## Charts

| Shortcut | Action |
|---|---|
| Type a timeframe (`15`, `4h`, `1D`), then Enter | Switch the active chart to that timeframe |
| Type a letter | Symbol search for the chart, with that letter; Enter or a click switches the chart |
| Alt+1 | Bar chart |
| Alt+2 | Candlesticks |
| Alt+3 | Line chart |
| Ctrl+G | Grid on or off |
| Ctrl+L | Volumes on or off |
| Ctrl+B | Objects list |
| + and − | Zoom the chart in and out |
| End | Scroll to the latest bar |
| Ctrl+F4 | Close the active chart |
| Tab and Shift+Tab | Next and previous chart in the layout |
| Alt+Enter | Maximise the active chart, or restore the layout |
| Shift+Right | Bar replay: step forward |
| Shift+Down | Bar replay: play or pause |
| F9 (on a chart in a backtest) | Place Order: plan a backtest order with lines on the chart |

These work while a chart has the keyboard focus (click it first):

| Shortcut | Action |
|---|---|
| Ctrl+Z and Ctrl+Y | Undo and redo changes to drawings and indicators |
| Ctrl+C and Ctrl+V | Copy and paste the selected drawings |
| Delete | Remove the selected drawings |
| Ctrl+Up and Ctrl+Down | Zoom the chart in and out |
| Left and Right | Scroll one bar; with Ctrl or Alt, ten bars |
| Shift+Left and Shift+Right | Scroll to the first loaded bar, or back to the latest |
| Escape | Cancel the current tool or drawing |
| Alt+T, Alt+H, Alt+J | Trend line, horizontal line, horizontal ray |
| Alt+V, Alt+C, Alt+F | Vertical line, cross line, Fibonacci retracement |
| Alt+R | Reset the chart view |
| Alt+I | Invert the price scale |
| Alt+L and Alt+P | Logarithmic and percent price scale |
| Shift-click | Measure |

## Mouse

| Action | Result |
|---|---|
| Right-click | Context menu for whatever is under the pointer |
| Mouse wheel on a chart | Zoom, keeping the latest bar in place; with Ctrl, around the pointer. Shift+wheel scrolls |
| Ctrl+click a drawing | Add it to the selection, or take it out |
| Ctrl+drag on a chart | Select every drawing with a point inside the box |
| Hold Ctrl while drawing | Turn the magnet the other way: off when it is on, strong when it is off |
| Double-click a Market Watch symbol | New order for that symbol |
| Double-click a position or order | Modify it |
| Double-click the line between charts | Make every chart in the layout the same size |
| Shift-drag the line between charts | Move the matching lines of the layout together |
| Middle-click a chart tab | Close the tab |
| Drag a symbol onto a chart | Show the symbol on that chart |
| Drag a trade line | Move the stop loss, take profit or pending price |
