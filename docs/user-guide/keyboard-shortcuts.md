# Keyboard shortcuts

OpenTerm5 follows MetaTrader 5's shortcuts where they exist. On macOS, use **Cmd** where this page says
**Ctrl**. Shortcuts are ignored while you type in a text field.

## General

| Shortcut | Action |
|---|---|
| F9 | New order |
| F11 | Full screen |
| Ctrl+1 to Ctrl+4 | Switch workspace: Trading, Copy Trading, Signals, Automation |
| Ctrl+O | Options (connection) |
| Ctrl+Shift+A | Switch between trading and analysis mode |
| Escape | Close the open dialog or menu, cancel the risk planner, or return to the cursor tool |

## Panels

| Shortcut | Action |
|---|---|
| Ctrl+M | Show or hide Market Watch |
| Ctrl+N | Show or hide the Navigator |
| Ctrl+T | Show or hide the Toolbox |
| Ctrl+D | Show or hide the Data Window |
| Alt+B | Show or hide Depth of Market |
| Ctrl+U | Symbols |

## Charts

| Shortcut | Action |
|---|---|
| Alt+1 | Bar chart |
| Alt+2 | Candlesticks |
| Alt+3 | Line chart |
| Ctrl+G | Grid on or off |
| Ctrl+L | Volumes on or off |
| Ctrl+B | Objects list |
| + and − | Zoom in and out |
| End | Scroll to the latest bar |
| Ctrl+F4 | Close the active chart |
| Alt+R | Tile chart windows |

These work while a chart has the keyboard focus (click it first):

| Shortcut | Action |
|---|---|
| Ctrl+Z and Ctrl+Y | Undo and redo changes to drawings and indicators |
| Ctrl+C and Ctrl+V | Copy and paste the selected drawing |
| Delete | Remove the selected drawing |
| Escape | Cancel the current tool or drawing |
| Alt+T, Alt+H, Alt+J | Trend line, horizontal line, horizontal ray |
| Alt+V, Alt+C, Alt+F | Vertical line, cross line, Fibonacci retracement |
| Alt+R | Reset the chart view (instead of tiling windows) |
| Alt+I | Invert the price scale |
| Alt+L and Alt+P | Logarithmic and percent price scale |
| Shift-click | Measure |

## Mouse

| Action | Result |
|---|---|
| Right-click | Context menu for whatever is under the pointer |
| Double-click a Market Watch symbol | New order for that symbol |
| Double-click a position or order | Modify it |
| Double-click a chart window title | Maximise the window |
| Middle-click a chart tab | Close the chart |
| Drag a symbol onto the chart area | Open a chart |
| Drag a trade line | Move the stop loss, take profit or pending price |
